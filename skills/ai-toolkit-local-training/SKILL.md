# 本地 AI-Toolkit 与图像 LoRA 训练

目标是让用户通过对话完成可复现的本地训练。此技能是指导智能体的说明，不是训练器，也不包含模型、数据或执行环境；不要假设本机有某个路径、显卡或已经安装的软件。实际操作受用户授权、机器权限、可用工具和上游许可约束。

1. 确认用户目标：文生图、参考图编辑、人物/风格/物体等，明确底模、数据来源、系统、显卡、目标路径以及是否希望实际训练。信息不足时先做只读检查并说明需要用户提供的数据。
2. 检查操作系统、驱动、GPU 空闲显存、RAM、磁盘、已有 AI-Toolkit 安装和运行任务；不要终止其他任务或覆盖已有数据。查 [AI-Toolkit 官方项目](https://github.com/ostris/ai-toolkit) 当前版本和实际模型的训练支持，推理可用不代表训练可用。安装、升级与离线细节按需读 [environment.md](references/environment.md)。
3. 依据目标训练器及模型当前文档，确认架构、模型变体、训练适配器、文本/视觉编码器、VAE、精度与许可。下载前估算空间，优先使用可信来源；核对版本、大小和可用的哈希，避免误用不完整文件。不要擅自替换现有底模。H3 Image 与 MOSS 的具体边界按需读 [models.md](references/models.md)。
4. 保留用户原始数据，检查图片、对应标注/参考图、坏图和重复；明确训练集与留出集。使用独立实验目录和配置，避免隐式继承旧 checkpoint。编辑任务的数据配对、文本引用和文生图要求不同，按当前架构的训练代码和文档设置。
5. 按用户授权先从少量样本做 GPU 小测：实际加载、至少一次梯度更新、检查有限 loss、保存 adapter 和预览，条件允许时验证正确断点恢复。报告实际通过与未通过的步骤；下载完整或推理可用不等于训练成功。用户明确请求正式训练后，结合空闲资源及小测结果启动并监控保存状态。
6. 使用留出样本和固定提示词、参考图、分辨率、种子与生成参数，比较原底模及不同时点的 LoRA；跨推理程序同种子不保证同一噪声。训练步数或 loss 无法单独证明效果，由用户审看并根据反馈调整。
7. 记录真实版本、硬件、组件、数据切分、配置、输出和验证状态。避免输出令牌或暴露私人数据；不要自动公开模型、素材或日志。修改和续训前先记录可回滚状态，不运行来源不明的脚本。

智能体的可用性和 Skill 安装入口因产品而异。遇到缺失权限、显存不足、未知模型支持或长期失败，应解释事实和可执行的下一步，不伪称已经完成。
