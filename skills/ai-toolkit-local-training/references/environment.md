# 环境、下载与续训

## 部署

- 先核对 [Ostris AI-Toolkit](https://github.com/ostris/ai-toolkit) 当前 README、目标架构支持和依赖；Windows 重点核对 Git、Python、Node、驱动、PyTorch/CUDA 对应关系。优先使用隔离的虚拟环境；已有环境先检查是否适用，避免重装覆盖。
- 升级前检查 git 工作树、活跃 GPU 训练、版本和 UI 数据库；保存可恢复的代码版本、配置、数据库和现有权重。不要 hard reset、清理用户文件或打断其他作业。
- 上游安装器和构建脚本可能联网及改环境；先阅读并核实来源与实际作用。保留用户模型、数据与输出的独立目录。服务开放到网络前，参考上游文档配置访问控制。
- 核实训练器要求的每个模型文件、精度和格式；可比较官方 Hugging Face 与 ModelScope 同文件的大小及 SHA256。支持续传并确认最终文件和全部分片，不以临时文件大小代替校验。
- 若用户希望离线使用，准备并验证 tokenizer、processor、配置、权重、适配器和缓存，再在离线模式下测试加载；不要将缺文件误判为显存不足。

## 训练与续训

- 用少量样本测试实际可训练分辨率、batch、dtype、缓存和卸载选项；CPU 卸载可省显存但可能增加内存和时间，并非一定能运行。
- 需要续训时先核对 checkpoint 的步数、模型、优化器状态与训练器恢复方式；备份输出并检查是否选择了正确 checkpoint。恢复后查看日志、当前步数和优化器状态，再判断是否真的续训成功。
- 训练中避免在保存时强行退出。不要把 loss 数值、生成了图片或成功启动当成最终质量证明。失败时记录具体报错、实际动作和尚未完成事项。
